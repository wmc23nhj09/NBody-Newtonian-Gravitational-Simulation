# NBody-Newtonian-Gravitational-Simulation
* A program written in C++ with SDL3 to simulate how bodies interact in deep space via gravity

# Overview
* This program was coded in C++, with SDL3 used as the visual help.

# Features
* Gravity
* Block Spawning~
* Collision Handeling~

# Future Features
* Energy Conservation
* Block Property Changing
* Scalable size
* Screen Scaling
* Time Scaling
* Angular Momentum
* Barnes hut algorithm
* etc.

# Known Limitations
* Doesn't allow interchangable sizes, or block properties
* Unscalable, so objects often fly out of screen
* Cannot delete objects
